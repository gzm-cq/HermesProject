## 一、5 层记忆体系

| 层级 | 名称 | 数据存储 | 生命周期 | 管理方式 | 实现状态 |
|------|------|----------|----------|----------|:-------:|
| L1 | Session DB | SQLite sessions | 会话级 | 自动，Hermes 内置 | ✅ |
| L2 | MEMORY.md | `~/.hermes/memories/MEMORY.md` | 跨会话 | Agent 手动写 + 定期清理脚本 | ✅ |
| L3 | USER.md | `~/.hermes/memories/USER.md` | 持久 | Agent 手动写 | ✅ |
| L4 | **经验域** (Hindsight) | PG `memory_units` (pgvector) | 长期 | 自动 retain + 聚类增强 | ✅ |
| L5 | **知识域** (知识树) | PG `knowledge_tree` (pgvector) | 长期 | 离线 builder + 在线 plugin | ✅ |

### 自进化飞轮

```
用户输入 → 知识导航插件(融合双域) → LLM 调用 → 更好输出
  → 对话产生新经验(Hindsight retain) + 新知识(知识树 post_llm_call)
  → 知识树周期维护(consolidate cron 周一10:30)
  → 下一轮 recall 更精准 → ↑
```

## 三、知识树管线（L5）

### Pipeline

```
扫描 → 阶段1+2(合并LLM提取) → 阶段3(准入去重) → 阶段4(树定位写入) → consolidate(周期维护)
```

### 维护命令


## 四、知识导航插件管线（L4+L5 融合）

```
用户消息 → 熔断器检查 → Hindsight recall(L4) + 知识树 recall(L5)
  → 排除标记记忆 → HitCounter → Compaction(超20轮降为1条)
  → 因果链boost → 跨域去重(threshold=0.65)
  → 分数过滤(时态衰减可选) → XML <memory-context> 注入
  → TaskTracker → 注入 user_message
```

### 关键机制

| 机制 | 参数 | 状态 |
|------|------|:----:|
| 熔断器 | 连续3次失败 → 熔断120s | ✅ |
| Compaction | 超20轮降为1条 | ✅ |
| 跨域去重 | threshold=0.65（Jaccard + 语义） | ✅ |
| 因果链 boost | rerank_score × 1.15（`KN_ENABLE_CAUSAL_CHAIN=true`） | ✅ |
| 标签区分 | `source="hindsight"` / `source="knowledge_tree"` | ✅ |
