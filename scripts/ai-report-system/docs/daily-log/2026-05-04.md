#### 3.2 踩坑记录
- `docker compose` 文件扩展名是 `.yaml` 非 `.yml`
- Weaviate 有 `profiles: - weaviate`，不会自动启动
- 文档在 Weaviate 未运行时上传会 tokens>0 但向量未存入
- Dify KB Retrieve API **不能传 `retrieval_model`**，只传 `query`+`top_k`
- API 安全扫描器拦截含 HTTP URL 的 inline 命令，需用 `docker cp` + `docker exec` 规避
- 上传文件到容器需先 cp 到 host 的 /tmp/，再 docker cp 到 dify-api-1:/tmp/
