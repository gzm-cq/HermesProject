# 执行计划

按已批准的计划逐步实施。每步完成后验证，遇到问题回退。

## 流程
1. **加载计划** — 读取 `docs/superpowers/plans/` 中的计划文件
2. **逐任务执行** — 按顺序执行计划中的每个任务
3. **每步验证** — 每个任务完成后运行测试/类型检查
4. **失败处理** — 任务失败时回退到上一个稳定状态，修复后继续
5. **完成检查** — 所有任务完成后运行完整测试套件

## 约束
- 按计划顺序执行，不跳步
- 每个任务完成后 commit
- 失败时优先修复而非跳过
- 计划外变更需先更新计划
