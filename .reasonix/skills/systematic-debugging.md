# 系统化调试

四阶段根因排查过程。

## 流程
1. **定位** — 通过观察确定 Bug 的具体表现和触发条件
2. **分析** — 追踪调用链，确定根因（而非症状）
3. **假设** — 提出修复方案，评估副作用
4. **修复** — 实施修复，验证 Bug 不再复现

## 原则
- 修复根因而非症状
- 一个 Bug 一个修复，不混入其他改动
- 修复后添加回归测试
