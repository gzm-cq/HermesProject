# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in HermesProject, please report it
privately **before** creating a public issue.

**How to report**:
- Open a **GitHub Security Advisory** at:
  https://github.com/gzm-cq/HermesProject/security/advisories/new

We will acknowledge receipt within 48 hours and aim to resolve validated
vulnerabilities within 14 days.

## Scope

This policy covers all source code and configuration files in this repository.
Third-party dependencies should be reported to their respective maintainers.

## Safe Harbor

We consider security research conducted in good faith to be protected activity.
You will not be pursued for legal action for discovering and reporting
vulnerabilities in accordance with this policy.
